# TODO-007. 読み込んだ写真を直近 3 枚、履歴として残す

**担当:** ai1

PWA で読み込んだ写真を、指定した四隅・ホーム側・駒の色・直した盤面と一緒に最近の 3 枚まで残し、
あとから選んでその続きから始められるようにする。アプリは誰でも開けるので、サーバーではなく
使っている端末の中（IndexedDB）にだけ残す。古いものから自動で消え、1 枚ずつ消すこともできる。

**2026-10-13 に完了:** PWA の最初の画面に「最近の写真」として直近 3 枚が出る（`analyzer/static/history.js`、IndexedDB）。
選ぶと四隅・ホーム側・駒の色・直した盤面・ダイスの続きから始められる。写真は長辺 2048px に縮めて保存し、
小さいスクリーンショットはそのまま。4 枚目で一番古いものが消え、✕ で 1 枚ずつ消せる。サーバーには残らない。
