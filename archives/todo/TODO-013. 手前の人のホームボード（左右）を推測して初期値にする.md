# TODO-013. 手前の人のホームボード（左右）を推測して初期値にする

**担当:** ai1

写真からは駒の並びしか分からず、ホームを左右逆にしても同じ並びの鏡像の局面になる。
四隅の画面の「手前の人のホームボード」を、ある程度自動で推測して初期値にしたい。

**2026-10-13 に完了:** gnubg の自己対戦（27 万局面）から、ポイントごとの駒の立ち方の出やすさを
`recognizer/home_prior.json` に学習し、左右どちらの読み方がありそうかを比べる（`recognizer/home_prior.py`）。
API は `home=auto` で推測し、応答の `home` に選んだ側を返す。PWA の四隅の画面に「自動」を足して既定にし、
盤面の画面に推測した側を出す（「左右を入れ替える」で直せる）。当たり具合はサンプル 23 枚すべて、
自己対戦で 99.9%（recognizer/README.md の「ホームボードの推測」）。
