- **担当:** Pi の Claude Code
- **足した日・PR:** 2026-10-16、analyzer 0.40.1（版の注記の向き）
- **背景:** ユーザーのスマホで「（新しい 0.39.0 は開き直すと出ます）」と出た。画面（app.js）が 0.40.0 なのに、サーバーの `/version` が 0.39.0 だった。
  静的ファイルはディスクから毎回読むので、`git pull` だけして `systemctl --user restart bganalyzer` をしていないと、画面だけ新しくなりサーバーの版は古いまま残る。
  これまでの注記は版の新旧を比べず、いつも「新しい …」と出していた
- **確かめ方:** `git pull && uv sync --frozen && systemctl --user restart bganalyzer` のあと、`curl -s http://127.0.0.1:8000/version` が 0.40.1 以上（TODO-058 の後は 0.40.2）か。ヘッドレスのブラウザで PWA を開き、ヘッダーに注記が出ないか
- **期待:** ヘッダーは「v0.40.1 · r…」（0.40.2 以降はその版）だけで、括弧の注記は出ない。サーバーが古いままなら「（サーバーは 0.40.0。再起動が必要）」、端末の app.js が古いなら「（新しい … は開き直すと出ます）」
