### 3. recognizer/board.py:714-717: `stack` は「山」ではなく「その列の同じ段にある円の数」
- 内容: コメントは「2 個以上の山と枠の間」だが、`stack` は x が 0.15 pitch 以内で同じ段（上下）にある `out`
  をすべて数える。間隔の制限（`line` の 2.3 pitch）も、内側にあることも見ていない。山でない確かな円
  （ダイスカップの縁、盤の模様など）が同じ列に 2 つあれば、その間や枠側にある弱い円も足される。
  また `out` はこのループの中で増えるので、先に足した弱い円が次の弱い円の `stack`・`inner` に入る
  （0.5.0 の「両側」の条件でも同じ）。
- 根拠: コードを読んだ。leather-cups はダイスカップを駒と数える写真で（README 106 行）、カップが同じ列に
  2 つ重なると条件を満たす。
- 実害は未確認（サンプルでこの条件を通ったのは leather-cups の 1 つだけで、`stack=3`）。

### 4. recognizer/board.py:715: 枠からの距離を正準の縁で測っていて、`count_from_circles` の `lip` を見ていない
- 内容: 数えるとき（`count_from_circles`）は、最初の駒の位置を行ごとに測った `lip`（-0.3〜0.8 pitch）で

  （各列の最初の駒の深さの中央値）と、重なった山の判定（間隔の中央値 < 0.85 pitch で数え方が変わる）
  にも入る。
- 根拠: コードを読んだ（board.py の `count_from_circles` の `lip` と `gaps`）。
