# 引き継ぎメモ

このリポジトリを別の GitHub アカウントや、別の Claude プロジェクトで続けるためのメモです。
コードの構成は [README.md](../README.md)、作業のルールは [CLAUDE.md](../CLAUDE.md)、
残りの作業は [TODO.md](../TODO.md) にあります。ここには、それ以外で
Claude のプロジェクト側にしか残っていなかった方針・進捗・運用ルールをまとめます（2026-10-12 時点）。

## 引き継ぎの手順

1. **コードを渡す**（GitHub の ytani01/bganalyzer）
   - 一緒に作業する: Settings → Collaborators から相手を招待する。
   - 完全に渡す: Settings → General → Transfer ownership で持ち主を変える。
     リポジトリの URL が変わるので、Claude の設定やクローン先も合わせて直す。
2. **相手側で新しい Claude プロジェクトを作る。** プロジェクトそのものを別アカウントへ移すことはできない。
   新しいプロジェクトのリポジトリにこのリポジトリをつなぎ、GitHub アカウントも連携する。
3. **プロジェクト指示に運用ルールを入れる。** 下の「運用ルール」をそのまま貼る。
4. 新しいプロジェクトの最初の依頼で、このファイルを読んでもらう。

## 目標と進み具合

スマホで撮った実物のバックギャモン盤の写真 → 盤面認識 → GNU Backgammon で解析
（勝率・ギャモン率・ピップ数）→ PWA で表示。

| ステップ | 内容 | 状態 |
|---|---|---|
| 1 | 盤面認識の試作（OpenCV） | 済 |
| 2 | gnubg による解析（サーバー側、FastAPI） | 済 |
| 3 | PWA（撮影・四隅タップ・手修正） | 済 |
| 4 | 実写真での調整 | 進行中 |

PR #1〜#7（gnubg API、README の図、認識の調整、gnubg 終了時の不具合修正、PWA、uv への移行、
README の uv と Docker の説明）はすべてマージ済み。

## 決まっていないこと・注意点

- **公開先は未定**（[TODO.md](../TODO.md) の TODO-002）。ホーム画面への追加には HTTPS が必要。
  gnubg の都合でサーバーレス関数は使えず、ワーカー1つで常駐させる。
- **`docker build` はユーザーの手元でまだ確認していない。** Claude のクラウド環境からは
  Docker Hub などに届かず試せなかった。Docker は必須ではなく、サーバーに公開するとき用。
  手元の開発は uv だけで足りる。
- **リポジトリを公開する前に `samples/` を直す。** photo1 には人の顔、screen2 には第三者の
  ツイートが写っているので、切り抜くかぼかす。

## 運用ルール（新しいプロジェクトの指示に入れる）

```text
- ユーザーとのやりとりは日本語で行う。
- リポジトリ <所有者>/bganalyzer で作業する前に main を pull し、リポジトリ直下の CLAUDE.md に従う。
- 自動マージ: スレッドが作った PR は、最新 main を取り込んでテストがすべて通り、差分を見直して
  問題がなければ、ユーザーの確認を待たずにそのスレッド自身がマージする。マージしたことは一言報告する。
  テスト失敗・未検証の重要事項・判断が必要な点がある場合はマージせず報告する。
```

GitHub に CI はないので、「テストが通る」は手元（Claude の環境）で `uv run pytest analyzer` が通ることを指す。
